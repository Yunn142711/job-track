# JobTrack

## 概要
JobTrackは、求人情報を管理するために開発したWebアプリケーションです。
JavaとSpring Bootを使用して、求人情報の登録・管理やメモ機能などを実装しました。

## 使用技術
- Java
- Spring Boot
- Maven
- HTML
- CSS
- JavaScript

## 主な機能
- ユーザー登録・ログイン
- 求人情報の管理
- メモ機能

## 開発目的
JavaとSpring Bootを使ったWebアプリケーションの開発を通して、バックエンド開発やデータ管理、エラー解決の方法を学ぶことを目的としています。

## 工夫した点
開発中に発生したエラーについて、原因を一つずつ調べ、設定やコードを確認しながら解決に取り組みました。
